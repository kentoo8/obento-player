# Obento Player

<img src="assets/preview.png" width="800" alt="Obento Player の再生画面。左側に操作ボタン、右側に動画のグリッドが並ぶ">

複数の動画をお弁当箱の仕切りのようにグリッド配置し、指定した時間間隔ごとにランダムなシーンへ自動切り替えするローカル動画プレイヤーです。macOS アプリとしても、ブラウザで `index.html` を直接開いても使えます。動画は外部に送信されず、再生はオフラインで行えます。

## 特徴

- 指定した時間間隔（5秒〜300秒）で、特定の動画に偏らないよう各動画を均等にシャッフルし、動画内のランダムな位置を自動抽出。
- 1 / 2 / 4 / 6 / 8 / 9 画面のレイアウトを選択。
- サイドバーを隠すシアターモードと、選んだセルを拡大する単体フォーカスに対応。
- 音量が大きい動画を自動で抑え、複数動画の音声バランスを調整。
- 速度、ミュート、シャッフル等のキーボードショートカットに対応。
- メニューはキーボードの矢印キー、Enter、Space、Escでも操作可能。
- キーボードで選んでいるボタンやメニュー項目は下端の短い線で分かります。クリックやドラッグを始めると線は消えます。
- 入力部品にもフォーカス枠は表示しません。キーボード操作中は入力欄の下線やスライダーのつまみの拡大で位置を示します。
- 非対応形式のファイルを追加したときは件数を通知。タッチ端末でもセル操作を利用可能。
- リセット時に先読み、切替タイマー、音声処理を安全に終了し、繰り返し利用可能。
- 情報の読み込みや再生に失敗した動画は候補から外す。再生中に失敗した場合は、可能なら次の動画へ自動的に切替。

## macOS 版のビルドと起動

Node.js 22.12.0 以上と npm が使える Mac で、このリポジトリのフォルダから実行します。

```sh
npm ci
npm run package:mac
```

`dist/Obento Player-darwin-arm64/Obento Player.app`（Apple シリコン）または `dist/Obento Player-darwin-x64/Obento Player.app`（Intel）をダブルクリックして起動します。ビルドした Mac と同じ CPU アーキテクチャ向けに作られます。開発中は `npm ci` の後に `npm start` で起動できます。

ブラウザで使う場合は、リポジトリ内の `index.html` を直接開きます。依存パッケージのインストールや Web サーバーの起動は不要です。

## 使い方

1. 画面内に動画ファイルをドラッグ＆ドロップするか、初期画面の「動画ファイルを選択」を押します。再生画面からは詳細メニューの「ファイルを追加」で動画を選べます。
2. 読み込み後に音声付きで再生が始まり、指定した間隔（初期値は10秒）でランダムなシーンへ切り替わります。ブラウザの自動再生設定によっては、音声付きの自動再生が制限されることがあります。

> **ヒント**: macOS アプリや Chrome / Edge では、動画フォルダをそのままドラッグ＆ドロップしてサブフォルダ内の動画もまとめて読み込めます。

## コントロール（サイドバー）

画面左側のサイドバーでアプリ全体を操作します。画面レイアウト、切替間隔、再生速度、縦動画の回転設定は次回起動時に復元されます。

| 操作 | 説明 | ショートカット |
|---|---|---|
| **App ロゴ** | 読み込んだ動画をすべてクリアして初期画面に戻る | — |
| **すべて再生 / 一時停止** | 全セルの再生を一括制御 | `Space` |
| **再生速度** | 0.5x 〜 4.0x までの再生速度を選択。変更時は画面左上に速度を表示し、次回起動時に最後の速度を復元 | `[` / `]` |
| **音声 ON/OFF** | 全体の音量を調整（ホバーでスライダー表示）。変更時は画面左上に音量を表示。大きすぎる動画は自動で抑制 | `M` / `↑` `↓` |
| **レイアウト** | 1 / 2 / 4 / 6 / 8 / 9 画面を選択 | — |
| **シャッフル** | ピン留めしていないセルのシーンを手動で切り替え | `S` |
| **切替間隔** | 詳細メニューの「間隔 (秒)」。5〜300秒の範囲で5秒刻み | — |
| **ファイルを追加** | 詳細メニュー内。ファイルを追加読み込み | — |
| **シアターモード** | 詳細メニュー内、またはサイドバー上部の畳むボタン。サイドバーを隠して動画のみを表示。左上の「表示を戻す」で解除 | セルの外で `F` |
| **縦動画を回転** | 詳細メニュー内。縦動画のみ 0度 / 270度 / 90度 の回転モードを切り替え。`Alt`（Mac では `Option`）を押しながらクリックすると逆順に切り替え | — |

## セル内個別コントロール

動画セル内の下部に表示されるコントロールバーから以下の操作が可能です。

マウスを操作パネルの上辺に重ねるとシークバーが表示されます。単体フォーカスでは画面下側にマウスを移動すると操作パネルが表示されます。タッチ端末では動画をタップするとパネルとシークバーが開閉し、グリッド表示中はパネルからピン留めや除外も操作できます。シークバーをクリック・タップ・ドラッグすると再生位置が変わります。キーボードでは `Tab` で「動画 N の再生位置」を表示し、矢印キーで調整します。

| ボタン | 説明 | ショートカット |
|---|---|---|
| **動画名** | macOS 版で、表示中の動画名を押すと、元ファイルのあるフォルダが開き、ファイルが Finder で選択される | `Tab` で移動し `Enter` または `Space` |
| **前の動画 / 次の動画** | グリッド表示中はセルの再生履歴を移動。履歴の末尾で「次の動画」を押すと新しいランダムなシーンを選ぶ。単体フォーカス中は読み込み順で前後の動画の先頭に移動し、リストの両端で一周する。単体フォーカス中の切り替えでは除外済みの動画を飛ばす | — |
| **10秒戻る / 進む** | 再生位置を10秒前後にシーク | `←` / `→` (ホバー中) |
| **再生 / 一時停止** | そのセル単体の再生を一時停止 / 再開 | — |
| **単体フォーカス** | そのセルを拡大し、間隔による自動切替を一時停止。動画の末尾まで再生すると読み込み順の次の動画へ進む。次に再生できる動画がなければ停止 | セルにポインターを置いて `F` で開始。`F` または `Esc` で解除 |
| **ピン留め** | グリッド表示中に `Alt`（Mac では `Option`）を押しながらセルにポインターを置くと表示。間隔による自動切替と手動シャッフルの対象から外す | `P` (ホバー中) |
| **ソロ再生** | その動画の音だけを出す。再度クリックで解除 | — |
| **除外** | グリッド表示中に `Alt`（Mac では `Option`）を押しながらセルにポインターを置くと表示。その動画を再生候補から外す | — |

## 対応ファイル形式

迷った場合は **MP4（H.264 映像・AAC 音声）** を使ってください。同じ拡張子でも、収録されている映像・音声コーデックによって、macOS アプリやブラウザでの再生可否が変わります。再生できない動画は、FFmpeg などでこの組み合わせに変換してから追加できます。

### 検証

Node.js が利用できる環境では、追加パッケージをインストールせずに検証できます。

```sh
npm test
npm run check
```

画面操作を変更した場合は [手動回帰チェック](docs/MANUAL_TESTING.md) も実施してください。
