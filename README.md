# Obento Player

<img src="assets/preview.png" width="800" alt="Obento Player Preview">

複数の動画をお弁当箱の仕切りのようにグリッド配置し、指定した時間間隔ごとにランダムなシーンへ自動切り替えするブラウザベースのプレイヤーです。

## 特徴

- 指定した時間間隔（5秒〜300秒）で、特定の動画に偏らないよう各動画を均等にシャッフルし、動画内のランダムな位置を自動抽出。
- 自由に動画レイアウトの切り替え可能（1枚〜9枚）。
- UIを隠す没入モードや、特定動画の全画面表示に対応。
- 音量が大きい動画を自動で抑え、複数動画の音声バランスを調整。
- 速度、ミュート、シャッフル等のキーボードショートカットに対応。
- メニューはキーボードの矢印キー、Enter、Space、Escでも操作可能。
- 非対応形式のファイルを追加したときは件数を通知。タッチ端末でもセル操作を利用可能。
- リセット時に先読み、切替タイマー、音声処理を安全に終了し、繰り返し利用可能。
- 情報の読み込みや再生に失敗した動画は候補から外す。再生中に失敗した場合は、可能なら次の動画へ自動的に切替。

## ダウンロード方法

1. 画面右上の緑色のボタン **[<> Code]** をクリックします。
2. **[Download ZIP]** を選択してファイルをダウンロードします。
3. ダウンロードされた ZIP ファイルを解凍（展開）します。

## 起動方法

解凍したフォルダの中にある `index.html` をダブルクリックするだけです。外部フォントなどを読み込まないため、ローカル環境（`file://`）とオフライン環境で動作し、サーバーは不要です。

## 使い方

1. 画面内に動画ファイルをドラッグ＆ドロップ（または「追加」ボタンから選択）
2. **自動的に音声付きで再生が開始され**、指定秒数ごとにランダムなシーンへ切り替わります。

> **ヒント**: モダンブラウザ（Chrome/Edgeなど）であれば、動画フォルダをそのままドラッグ＆ドロップして中身を一括読み込みすることが可能です。

## コントロール（サイドバー）

画面左側のサイドバーからアプリ全体の操作を行います。`F`キーでシアターモードに切り替えると、サイドバーを隠して動画のみに集中できます。

| 操作 | 説明 | ショートカット |
|---|---|---|
| **App ロゴ** | クリックで全リセット（初期状態に戻す） | — |
| **再生 / 停止** | 全セルの再生を一括制御 | `Space` |
| **再生速度** | 0.5x 〜 4.0x までの再生速度を選択。変更時は画面左上に速度を表示 | `[` / `]` |
| **音声 ON/OFF** | 全体の音量を調整（ホバーでスライダー表示）。変更時は画面左上に音量を表示。大きすぎる動画は自動で抑制 | `M` / `↑` `↓` |
| **レイアウト** | 1 / 2 / 4 / 6 / 8 / 9 画面を選択 | — |
| **シャッフル** | 手動で全セルを即座に切替。動画を均等に一巡し、同じシーンの連続を抑制 | `S` |
| **切替間隔** | 詳細メニュー内。シーンが切り替わるまでの秒数（5〜300秒） | — |
| **追加** | 詳細メニュー内。ファイルを追加読み込み | — |
| **シアターモード** | 詳細メニュー内、またはサイドバー上部の畳むボタン。サイドバーを隠して動画のみを表示。左上にカーソルを近づけると戻すボタンを表示 | `F` |
| **回転切替** | 詳細メニュー内。縦動画のみ 0度 / 270度 / 90度 の回転モードを切り替え。Alt+クリックで逆順に切り替え。設定は次回起動時も復元 | — |

## セル内個別コントロール

動画セル内の下部に表示されるコントロールバーから以下の操作が可能です。

| ボタン | 説明 | ショートカット |
|---|---|---|
| **前の動画 / 次の動画** | そのセルで再生する動画を前後に切り替え。単体フォーカス中は読み込み順で前後の動画の先頭に移動し、リストの両端で一周する。除外済みの動画は飛ばす | — |
| **10秒戻る / 進む** | 再生位置を10秒前後にシーク | `←` / `→` (ホバー中) |
| **▶ / ⏸** | そのセル単体の再生を一時停止 / 再開 | — |
| **フォーカス** | そのセルを全画面表示 | `F` (入/切) / `Esc` (切) |
| **ピン留め** | `Alt` を押しながらホバーで表示。自動切替を停止 | `P` (ホバー中) |
| **ソロ再生** | その動画の音だけを出す。再度クリックで解除 | — |
| **除外** | `Alt` を押しながらホバーで表示。その動画を候補から削除 | — |

## 対応ファイル形式

| 形式 | 対応 |
|---|---|
| `.mp4` (H.264) | ✅ 推奨・全ブラウザ |
| `.webm` (VP8/VP9) | ✅ Chrome / Firefox / Edge |
| `.ogg` / `.ogv` | ✅ Firefox 中心 |
| `.mov` / `.avi` / `.mkv` | ❌ ブラウザに依存 |

非対応動画は ffmpeg などで .mp4 に変換することをオススメします。

## 開発・リファイン

今後の品質改善、コード分割、アクセシビリティ、性能改善の方針は [リファイン計画](docs/REFINEMENT_PLAN.md) を参照してください。

現在のモジュール構成と状態の所有範囲は [アーキテクチャ](docs/ARCHITECTURE.md) にまとめています。

長時間再生や多数の動画を扱う変更では [性能確認](docs/PERFORMANCE.md) の条件で比較します。

対象ブラウザと制約は [対応環境](docs/SUPPORT.md)、配布前の確認項目は [リリースチェックリスト](docs/RELEASE_CHECKLIST.md) を参照してください。

開発時は、サーバーやビルドを前提にせず `index.html` を直接開いて使えること、動画データを外部へ送信しないことを維持します。ユーザーから見える機能や操作を変更した場合は、このREADMEも同時に更新します。

### 検証

Node.js が利用できる環境では、追加パッケージをインストールせずに検証できます。

```sh
npm test
npm run check
```

画面操作を変更した場合は [手動回帰チェック](docs/MANUAL_TESTING.md) も実施してください。
