# 手動回帰チェック

リリース前、または再生・UI関連の変更後に確認する。異なる長さの動画を3本以上用意すると、シャッフルも確認しやすい。

## 起動と読み込み

- [ ] `index.html` を直接開いて初期画面が表示される。
- [ ] ファイル選択とドラッグ＆ドロップの両方で動画を追加できる。
- [ ] 対応していないファイルが動画一覧へ混入しない。
- [ ] ロゴから全リセットでき、再度動画を追加できる。

## 再生とシャッフル

- [ ] 追加後に動画が再生され、指定間隔で切り替わる。
- [ ] 手動シャッフルでピン留めされていないセルが切り替わる。
- [ ] 動画の長さが異なっても、長い動画だけに選択が偏らない。
- [ ] 動画数がセル数以上なら、同じ動画が同時に重複しない。
- [ ] 前後ボタンでセルの履歴を移動できる。
- [ ] 除外した動画が以後の候補に現れない。

## 表示と操作

- [ ] 1、2、4、6、8、9画面へ切り替えられる。
- [ ] フォーカス、シアターモード、ピン留めを開始・解除できる。
- [ ] 縦動画の回転方向を通常クリックとAlt+クリックで変更できる。
- [ ] Space、S、F、M、P、矢印、`[`、`]` の各ショートカットが機能する。
- [ ] 狭い画面でも主要ボタンが重なったり画面外へ出たりしない。

## 音声

- [ ] 全体ミュート、音量変更、ソロ再生を開始・解除できる。
- [ ] 再生速度を変更すると、表示中のすべての動画へ反映される。
- [ ] 音声の大きな動画があっても、クリッピングや急激な音量差が抑えられる。

## 終了条件

- [ ] `npm test` が成功する。
- [ ] `npm run check` が成功する。
- [ ] ブラウザのコンソールに未確認のエラーがない。
