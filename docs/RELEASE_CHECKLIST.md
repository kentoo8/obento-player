# リリースチェックリスト

## 自動確認

- [ ] `npm test` が成功する。
- [ ] `npm run check` が成功する。
- [ ] `git diff --check` が成功する。

## 動作確認

- [ ] [手動回帰チェック](MANUAL_TESTING.md)を主対象ブラウザで実施する。
- [ ] `index.html` を `file://` で直接開いて利用できる。
- [ ] ネットワークをオフにしても初期画面と主要操作が機能する。
- [ ] 対応・非対応動画の通知が正しく表示される。
- [ ] リセット後に動画、音声、タイマーが残らない。
- [ ] 必要に応じて[性能確認](PERFORMANCE.md)の標準シナリオを実施する。

## 文書と差分

- [ ] ユーザーから見える変更がREADMEへ反映されている。
- [ ] モジュール構成の変更がアーキテクチャ文書へ反映されている。
- [ ] 対応環境または制約の変更が対応環境文書へ反映されている。
- [ ] コミットが目的ごとに分かれ、コミットメッセージが規約に従っている。
