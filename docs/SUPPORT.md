# 対応環境

## 基本方針

Obento Player はビルドやWebサーバーを必要とせず、展開した `index.html` を直接開いて利用できることを配布条件とする。フォントを含め外部リソースへ依存せず、オフラインで動作する。

## 対象ブラウザ

- Chrome、Edge: 主対象。動画ファイルとフォルダのドラッグ＆ドロップを確認する。
- Firefox: 動画ファイルの選択とドラッグ＆ドロップを確認する。フォルダ操作はブラウザAPIの差異により制限される場合がある。
- Safari: 対応コーデックの動画ファイル選択と基本再生を確認する。形式によって再生可否が異なる。

各ブラウザは、テスト時点の安定版を対象とする。Internet Explorerは対象外とする。

## 動画形式

拡張子だけで再生可否は保証できない。同じコンテナ形式でも、映像・音声コーデックがブラウザに対応している必要がある。迷った場合はH.264映像とAAC音声を格納したMP4を推奨する。

## プライバシーとネットワーク

- 選択した動画はブラウザ内のBlob URLとして扱い、外部へ送信しない。
- アプリ本体は外部スクリプト、スタイル、フォントを読み込まない。
- ブラウザ拡張機能やブラウザ自身の通信は、このアプリの管理対象外とする。
